1. Sobre o Projeto

O Boots'N Pots é um aplicativo web voltado para identificação e catalogação de plantas, desenvolvido como Trabalho de Conclusão de Course (TCC) da Fatec Aracatuba (Centro Paula Souza).

O app permite que o usuário fotografie plantas pela câmera do celular, identifique a espécie e aprenda sobre seus cuidados, usos medicinais, culinários e dicas de cultivo. Todo o conteúdo está em português brasileiro.

2. Funcionalidades do App

  • Captura de fotos — Tirar foto de plantas pela câmera do celular
  • Identificação de espécies — Reconhecimento da planta a partir da imagem capturada
  • Catálogo de plantas — Navegar, buscar e filtrar por categorias (medicinais, culinárias, aromáticas)
  • Informações detalhadas — Descrição, nomes populares, benefícios, receitas e dicas de cultivo
  • Cuidados com a planta — Informações de rega, luz solar, temperatura e uso principal
  • Coleções pessoais — Organizar plantas em coleções (Minhas Plantas, Favoritas, Medicinais)
  • Perfil do usuário — Estatísticas de plantas identificadas e coleções criadas

3. Plataforma

Atualmente o projeto é uma aplicação web responsiva construída com foco em experiência mobile. O layout simula um frame de celular (largura máxima de 430px) para testes no navegador.

7. Arquitetura e Padrões

  • Roteamento: HashRouter (compatível com hosting estático no Render)
  • Transições: Animações CSS customizadas (slide esquerda/direita/fade) baseadas na ordem das rotas
  • Layout: Mobile-first com frame de celular simulado (max-width: 430px)
  • Dados: Todos hardcoded (mock data) — sem backend, sem API, sem banco de dados
  • Estado: Cada página é isolada com estado local — sem gerenciamento de estado global
  • Estilos: CSS puro com custom properties — um arquivo CSS por página

8. Problemas e Pendências

Lista completa dos problemas encontrados durante a revisão do código:

Alta Prioridade

  • Componentes não extraídos — A pasta src/components/ está vazia. A barra de navegação inferior (bottom-nav) está duplicada em 5 páginas diferentes e 5 arquivos CSS distintos.
  • CSS duplicado — As classes .bottom-nav, .nav-item, .camera-button, .camera-circle estão copiadas idênticas em Home.css, Search.css, Collection.css, Profile.css e PlantDetail.css.
  • PlantDetail sempre mostra a mesma planta — independentemente de qual planta o usuário clica, a página sempre exibe "Hortelã-Pimenta". A rota não aceita parâmetros.

Média Prioridade

  • Sem autenticação real — O login é apenas navegação. Botões de login social (Google/Apple) não fazem nada.
  • Sem integração de câmera — A página Camera é apenas um mockup visual. Não usa a API getUserMedia() do navegador.
  • Sem identificação de plantas — Apesar de ser o core do app, não existe integração com IA/ML ou API de reconhecimento de imagens.
  • Filtro de categorias incompleto — No Search, os botões de categoria (Medicinais, Culinárias, Aromáticas) só mudam o visual. O filtro real é apenas por texto.
  • Sem gerenciamento de estado — Não existe React Context, Redux, Zustand ou qualquer forma de compartilhar dados entre páginas.
  • Dados hardcoded — "Marina Silva", "marina@email.com", todas as plantas e coleções são dados fixos. Nada vem de um backend.

Baixa Prioridade

  • Scripts com path hardcoded — O setup.bat usa C:\Users\Usuario\Desktop em vez de C:\Users\User\Desktop, o que falharia nesta máquina.
  • Sem testes — Não existe nenhum arquivo de teste, nem bibliotecas de teste nas dependências (Jest, Vitest, React Testing Library).
  • Link "Cadastre-se" sem handler — O link de cadastro no Login está estilizado mas não tem função associada.

10. Resumo

O Boots'N Pots é um projeto front-end em React + TypeScript que demonstra uma interface polida e bem diseñada para um app de identificação de plantas. A experiência visual está avançada com transições suaves, layout mobile-first e design temático verde/natureza.

Porém, é um protótipo estático — ainda falta implementar: backend, banco de dados, autenticação, integração com câmera real, serviço de identificação por IA, e extrair componentes compartilhados para reduzir a duplicação de código.

Próximos passos recomendados:
  1. Extrair componentes compartilhados (BottomNav, PlantCard)
  2. Criar React Context para gerenciamento de estado global
  3. Integrar API de identificação de plantas (ex: PlantNet, iNaturalist)
  4. Implementar autenticação real (JWT + backend)
  5. Adicionar testes unitários e de integração
  6. Corrigir paths nos scripts de automação
